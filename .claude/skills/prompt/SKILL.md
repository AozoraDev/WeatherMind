# 提示词编写

分层架构，自底向上逐层填写，层间不混写；无关层省略。

## 分层模型
1. **角色层**：身份、立场、能力边界（谁 + 不越权做什么）
2. **背景层**：环境、输入数据、上下文来源（可拿到什么）
3. **任务层**：目标、步骤、流程（做什么、按什么顺序）
4. **约束层**：边界、禁做、质量门槛（负面规则集中于此）
5. **输出层**：格式、长度、语言（可验证的具体规格）

## 写法
- 每层独立小节，极简条目；动词开头祈使句，禁空话形容词（"请务必""高质量"）
- 具体可验证（长度/格式/示例）优先于模糊要求
- 负面约束集中在约束层，不散落
- 完成后自检：目标是否唯一、约束是否可执行、输出是否可验证
